Démo jouable

Le coffre hors-ligne, dans votre navigateur

Le coffre, le mode sous contrainte, l’inventaire, les calculs d’autonomie, les conversions MGRS et la recherche dans les fiches sont le code réel de l’application, compilé pour le navigateur. Seule l’interface est propre à la démo.

Codes de démonstration

482915 Code maître : ouvre le vrai coffre
730264 Code de contrainte : ouvre le leurre, sans aucun signe à l’écran

À essayer

  1. Ouvrez avec le code maître : 3 personnes, l’eau limite l’autonomie.
  2. Dans Stock, retirez 10 L d’« Eau en bidons » : le lot qui périme le plus tôt part en premier.
  3. Verrouillez, puis ouvrez avec le code de contrainte : un autre inventaire, la même interface.
  4. Saisissez cinq faux codes : le coffre se bloque 30 secondes.
  5. Cherchez « severe » dans les fiches : la recherche ignore les accents.

Coulisses

Simulé dans la démo

  • Le chiffrement SQLCipher : les bases sont en mémoire, mais chacune ne s’ouvre qu’avec la clé dérivée du bon code.
  • Le Keychain du téléphone : l’état du coffre est gardé en mémoire.
  • Argon2id utilise 8 Mio au lieu de 64 Mio, car le JavaScript pur est plus lent que le module natif.
  • Rien n’est conservé : recharger la page recrée un coffre neuf.
